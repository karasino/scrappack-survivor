# Scrappack Survivor

Roguelike с электрическими цепями предметов в рюкзаке. Phaser рисует игру внутри Canvas/WebGL; TypeScript собирается через Vite. Язык игрового интерфейса — английский.

## Локальное окружение

- Node.js **24.x**, npm из этого окружения. Версия указана в [.nvmrc](.nvmrc); с установленным nvm достаточно `nvm use`.
- Google Chrome с поддержкой headless и Canvas/WebGL. По умолчанию `google-chrome`; для другого расположения передать `CHROME_BIN=/absolute/path/to/chrome`.
- Зависимости берутся из [package-lock.json](package-lock.json), обновление зависимостей не является частью обычного запуска.

```bash
npm ci
npm run doctor
npm run check
```

`doctor` проверяет среду и локальный порт **4175**, но ничего не устанавливает и не останавливает чужие процессы. Для Chrome используются временный профиль и программный WebGL (SwiftShader). Проверки требуют разрешения на запуск браузера и прослушивание `127.0.0.1`; `EPERM` означает ограничение среды, а не провал игровой механики.

## Запуск игры

```bash
npm run dev
```

Открыть адрес из вывода Vite. WASD/стрелки или клик по соседней клетке — шаг, Space — ожидание, E — контекстное действие, B — переключение компактного вида, R — поворот переносимого предмета. Рюкзак управляется мышью. `NEW RUN` начинает новый забег после завершения.

## Проверки

| Команда | Результат |
| --- | --- |
| `npm run doctor` | Диагностика Node, зависимостей, Chrome и порта |
| `npm run check:docs` | Ссылки, бюджеты кратких документов, структура задач |
| `npm run build` | TypeScript и production-сборка |
| `npm run test:combat-ui` | Бой, энергия, ввод, тултипы и визуальные состояния |
| `npm run test:visual` | Только визуальная часть боевого набора |
| `npm run test:exploration` | Исследование, монстры, переходы и раскладки |
| `npm run test:crafting` | Материалы, сборка, лечение, награды и полный забег |
| `npm run test:harness` | Регрессии диагностики и проверки документов |
| `npm run check` | Doctor → документы → harness → build → бой → исследование → сборка |

Все игровые наборы проверяют Canvas и WebGL. Запускать их последовательно: они используют общий порт 4175. Снимки и диагностика — в игнорируемом Git каталоге `artifacts/`. Подробности — [в правилах проверки](docs/verification.md).
