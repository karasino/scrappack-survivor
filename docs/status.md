## Ограничения и незакрытые вопросы

- `strict` TypeScript не включён; отдельная миграция ещё не согласована.
- Core-проверки пока исполняются через Vite/Chrome. Отдельного набора без браузера нет.
- Процедурные сектора, случайные свойства оборудования и сохранение на диск не реализованы. Следующих боссов/секторов в маршруте нет.
- Баланс и длительный комфорт отдельно не приняты; коммерческие права на картинки не проверены владельцем.
- Сборка предупреждает о крупном JS-чанке; это не ошибка сборки.
- Git origin настроен на https://github.com/karasino/scrappack-survivor.git без токена. Ранее сохранённый токен ещё нужно отозвать в GitHub; подтверждения отзыва нет. Это не блокирует локальный harness.
