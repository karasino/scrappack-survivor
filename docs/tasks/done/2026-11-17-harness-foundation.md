# Базовый harness

## Цель и критерии готовности

Сократить постоянно загружаемый контекст; сохранить актуальные правила и историю; дать Codex в IDE воспроизводимые проверки и передачу незавершённой задачи. AGENTS ≤ 8192 байт, status ≤ 4096 байт; локальные ссылки и формат задач проверяются; игровые наборы проходят в Canvas/WebGL; сбои окружения/браузера объясняются и завершаются ограниченно.

## Решения и границы

17.11.2026 пользователь попросил реализовать согласованный план целиком. Один локальный skill, один файл на задачу, документация по подсистемам, Node 24, существующий Chrome/CDP runner, последовательные npm-команды. Ручная приёмка остаётся в чате перед локальным коммитом.

Игровые API/правила, strict TypeScript, рефакторинг GameScene и тестовый framework не меняются. CI, отдельный core-runner и оценка агента — последующие задачи. Изменение Git origin требует корректного URL; токен отзывает владелец.

## План

1. Сохранить исходный AGENTS без потери байтов и извлечь актуальные правила в документы.
2. Добавить короткие инструкции, status, шаблон/процесс задач и scrappack-task.
3. Добавить doctor, check:docs, агрегатор check и диагностику runner.
4. Проверить отказные сценарии harness и все игровые наборы.
5. Передать ручной чек-лист; после подтверждения закрыть задачу и сделать локальный коммит.

## Известные проблемы

В текущем окружении sandbox запрещает локальный listen; браузерным проверкам нужен разрешённый запуск. Origin настроен на предоставленный пользователем HTTPS-адрес без токена. Подтверждения отзыва прежнего токена в GitHub ещё нет; это не блокирует локальный harness. Ограничения доказательств перечислены выше: фактический объём чтения контекста, автоматический подбор навыка и сценарий замечаний отдельно не заявляются проверенными.
