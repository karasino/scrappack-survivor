# Бой и лечение

Реализация: [CombatEngine](../../src/game/core/CombatEngine.ts), [RunState](../../src/game/core/RunState.ts). Энергия описана [отдельно](inventory-power.md).

## Боевой ход

- Атака требует ID собственного оружия inventory; броня необязательна. Обесточенные предметы используют базовые характеристики.
- Источник выбора — `Item.isSelectedForTurn`, максимум одно оружие и одна броня. UI получает ID непосредственно перед действием.
- Общий энергоплан определяет оплачиваемые усиленные либо базовые эффекты. Щит временный, не постоянное HP.
- Ответ врага выполняется даже после смертельного попадания по нему. Затем списывается энергия, удаляются пустые батареи и определяется исход. Одновременная смерть — поражение, без награды.
- Конструктор принимает текущие HP для новой встречи; автоматического восстановления нет. `processTurn` — оболочка атаки над `processAction`.

## Аптечка

В бою Medkit заменяет атаку: фактическое лечение до max HP и расход предмета → план только брони → щит и ответ врага → оплата/исход. Оружие не требуется, не атакует и не расходует заряд. При полном HP, смерти или отсутствии собственной аптечки действие запрещено.

В исследовании Medkit расходует мировой ход с фазой монстров; в мастерской мир не движется. Использовать безопасную команду RunState, не вызывать внутреннее потребление в обход ExplorationEngine. Значения читать из модели/каталога.

## Встречи и исход

`RunState.beginEncounter` разрешён при исследовании без переноса. Начальный HP берётся из забега; запоминается инициатор. В бою карта, мировой счётчик и RNG заморожены.

После атакующей победы герой завершает шаг на клетку врага, затем получает добычу там. После нападения монстра герой остаётся на месте. Награда выдаётся один раз; прерванная фаза мира не продолжается. Награда босса — [в прогрессии](crafting-progression.md).

RunState синхронизирует HP из движка и при исключении. После частичной ошибки UI показывает фактическое состояние, блокирует продолжение и не повторяет действие. UI не откатывает урон самостоятельно.

## Проверка

`test:core` — оплата, базовые эффекты, лечебный энергоплан, исходы и награды. `test:combat-ui` — выбор, согласованность UI с боем, ошибки и жизненный цикл. `test:crafting` — интерфейс лечения, ресурсов и наград. В ручном чек-листе объяснять стоимость лечения и ответ при смертельном попадании. [Матрица](../verification.md).
